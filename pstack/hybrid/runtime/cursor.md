# hstack Cursor runtime

Invoke `/hstack-poteto-mode` for hstack and `/hstack-setup-pstack` for its model setup. Use the full `hstack-` identifier even when the host also displays a plugin namespace. Bare `poteto-mode` and `setup-pstack` belong to upstream pstack. Installation alone does not select hstack for unrelated requests.

Resolve every bundled workflow and named agent through [this package's skill map](../../SKILL-MAP.json), whose paths are relative to this package's root. Read the exact mapped file, including sibling skills selected by inherited labels such as `how`. Never substitute a global unprefixed pstack skill or agent. A missing mapped file is an installation fault to report and repair within the authorized scope. Upstream prose that names canonical `pstack/skills/` files means the corresponding mapped package file; do not fetch upstream `main` to replace the selected hstack workflow. Preserve actual source URLs when inspecting upstream evidence.

Use `hstack-poteto-agent` and `hstack-comment-sicko` when those named agents are available. If personal skill synchronization exposes skills without named-agent registration, read the mapped agent instructions and brief a supported generic worker with those instructions instead. Give every delegate absolute paths to its hstack workflow, agent prompt, and this adapter, plus its bounded task and ownership. Unavailable named agents never justify selecting the original `poteto-agent` or `Comment Sicko`.

Preserve native Task, model-role rules, cloud lifecycle tools, and Cursor metadata. Do not treat Codex model identifiers as Cursor model identifiers.

For implementation tasks, apply [the hybrid execution policy](hybrid.md): Cursor builds, Codex reviews, and Codex can rescue a blocked implementation. A user's per-task native-only or different builder/reviewer instruction overrides that default. Pure explanations, planning, and questions do not launch a paid CLI review automatically.

Read the runner's `--help` and [local setup](../docs/cursor-local.md) before first use. If Codex is absent or unauthenticated, report the missing prerequisite; do not call a Cursor GPT-model Task a Codex CLI review. Do not claim the hybrid review passed when only native review ran.

A delegated review/rescue worker executes only its assigned role. It must not recursively invoke hybrid routing. Never send work to a cloud service, merge, publish, or schedule anything beyond the user's authorized scope.
